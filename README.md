# Instancy 2.0
Arquivos iniciais do aplicativo mobile-first, feitos com HTML, CSS e JavaScript.

## Publicar no GitHub Pages pelo celular
1. Extraia o ZIP no celular.
2. No seu repositório GitHub, envie `index.html`, `style.css`, `script.js` e `manifest.webmanifest` para a pasta principal.
3. Faça o commit.
4. Abra Settings > Pages, escolha Deploy from a branch, branch `main` e pasta `/ (root)`.
5. Salve e aguarde o endereço do site.

## Recursos incluídos
- Entrada com nome e senha demonstrativa local.
- Perfil e papel de parede local.
- Mural de fotos/vídeos com curtidas locais e exclusão.
- Editor de fotos com texto, filtros, brilho, contraste, saturação, emoji e exportação PNG.
- Coleção de emojis.
- Prévia de vídeo com filtros e texto de referência.
- Exportação de backup JSON.

## Limitações
O mural e o perfil não são compartilhados com outras pessoas. A senha não é autenticação segura. O editor de vídeo mostra filtros apenas na prévia; o download mantém o vídeo original. Limpar dados do navegador pode apagar os dados locais, então faça backups.
